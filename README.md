# Real Melee Weapons

Minecraft 1.20.1 Forge mod - Realistic melee weapons + tactical armor.

## Features
- 16 melee weapons inspired by real life
- 2 armor sets: Tactical & Scout
- Creative tab included

## How to get the JAR (Recommended)

1. Create a new GitHub repository
2. Upload all files from this folder to the repo
3. Go to **Actions** tab → run the workflow (or just push to main)
4. When it finishes, download the artifact named `realmelee-jar`
5. Put the `.jar` into your `mods` folder

## Manual Build
```bash
./gradlew build
```
JAR will be in `build/libs/`
